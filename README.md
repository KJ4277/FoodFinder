# FoodFinder

Website to Access FoodFinder: https://foodfinder.fwh.is/login.php

FoodFinder is a website which allows users to enter an ingredient, and choose dietary filters (vegan, vegetarian, gluten free). A list of recipes for meals is outputted, with the choice to view the instructions and favourite the recipe. Users can access the account page which allows them to see their favourited meals and alter their login details.

- All passwords are hashed and kept secure
- Account creation is only necessary to keep favourited meals saved under your account
